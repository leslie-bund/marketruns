# Market Runs Archive

The archive queue consumer (ADR-0010): Durable Objects retire by sending snapshots to the `ARCHIVE_QUEUE`, and this worker persists them to Postgres (durable record) and R2 (media) — `product.retired` and `cart.retired` snapshots, `run.started`/`run.retired` markers on the `live_runs` index (ADR-0017), and `settlement.released` records with their double-entry ledger legs, all idempotent on redelivery. It is also the read path for everything historical: `GET /reputation` (computed reputation per participant), and the ops-oversight endpoints `GET /admin/runs` (union of `live_runs` and `runs_archive`, filterable by `market`, `status`, `runnerId`, and `kind=live|archived` — the `runnerId`+`kind=live` pair backs runner run discovery, ADR-0018), `/admin/disputes`, `/admin/settlements`, `/admin/ledger`, and `/admin/ops-health` (the ADR-0013 expansion gate). The edge fronts all of these with fail-closed, schema-validated proxies; clients never call the archive directly. Local dev: `infra/dev-servers.sh` (see `infra/README.md`).
